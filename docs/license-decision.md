# Лицензия исходников: решение KW-1024

Статус выбора: **accepted — MIT**, 07.10.2026. Владелец явно выбрал «MIT + report-v1 (рекомендую)». Решение распространяется на собственные исходники, публичный API, mapper и собственные примеры/генератор.

`fonts/DejaVuSans.copyright` — уведомление о шрифте Bitstream Vera / DejaVu. Это не лицензия кода `src/`.

[Первичный текст MIT](https://opensource.org/license/mit) разрешает использование, изменение и распространение, включая коммерческое, при сохранении уведомления и текста лицензии. MIT выбрана для встраиваемой библиотеки. Рассмотренная альтернатива [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0) содержит явное предоставление патентных прав; сохранение NOTICE требуется, если исходный Work содержит такой файл.

Корневой файл `LICENSE` содержит текст MIT. Строка copyright — `Copyright (c) 2026 Artem Klen`, как у автора репозитория. Уведомление о шрифте остаётся в `fonts/DejaVuSans.copyright`. Публичный заголовок помечен `SPDX-License-Identifier: MIT`.

Сторонний шрифт в `fonts/` распространяется только вместе со своим copyright-файлом. Синтетический `tests/corpus/truncated-hmtx.ttf` написан для проверки границ и не является шрифтом DejaVu.

Корневой `LICENSE` и `fonts/DejaVuSans.copyright` входят в исходный архив. KW-1025 остаётся открытой, пока нет live CI и независимой приёмки выпуска. [Согласованное решение](https://linear.app/klenwriter/document/ki-xml-pdf-01-predlozhenie-licenzii-i-xml-profilya-report-v1-9656627df2c9) не является публикацией.
