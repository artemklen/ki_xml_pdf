# Профиль XML: решение KW-1021

Статус: **accepted / continue**, 07.10.2026. Владелец явно выбрал «MIT + report-v1 (рекомендую)» в ответ на предложение лицензии и XML-профиля.

Для первого открытого релиза выбран собственный публичный формат отчётов `report-v1`. Контракт: [report-v1.md](report-v1.md). Разрешённый пример создан для проекта: [report-v1.xml](../examples/report-v1.xml); ожидаемый логический текст: [report-v1.expected.txt](../examples/report-v1.expected.txt). Это собственные fixtures, а не документы клиента или доказательство спроса на неизвестную внешнюю схему. Они входят в принятое решение о MIT для исходников и собственных примеров; применение лицензии к дистрибутиву выполняет KW-1024.

[Согласованное решение в Linear](https://linear.app/klenwriter/document/ki-xml-pdf-01-predlozhenie-licenzii-i-xml-profilya-report-v1-9656627df2c9).

Встроенный `report-v1` выбирается `--profile report-v1` и `KiOptions.profile = KI_PROFILE_REPORT`. `records-v1` остаётся профилем по умолчанию. Решение о профиле не является разрешением на публикацию, пока выпуск не принят.

Неизвестный заказной формат подключается отдельным адаптером; совместимость с ним не заявляется. Сравнение с прежним конвертером и Apache FOP пока недоступно. Исторические измерения `records-v1` описаны в [contract.md](contract.md).
